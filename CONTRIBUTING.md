# Contributing

Contributions should include focused changes, relevant tests, and updated documentation when behavior or licensing changes. Do not claim Linux distro, package-manager, GUI, or terminal-protocol support unless it is implemented and verified on Android devices. Before adding downloaded binaries, document provenance, checksums, architecture, license, and any source or notice obligations.

Build locally with JDK 17, Android SDK 35, NDK/CMake 3.22.1, then run `gradle testDebugUnitTest assembleDebug`.
